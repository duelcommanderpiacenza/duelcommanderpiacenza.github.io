Events/entries/matches are **drill-down panels**, not top tabs — click into a league to manage its events, click into an event to manage its entries/matches (`admin/js/events-admin.js`, `entries-admin.js`, `matches-admin.js`). **Online leagues and events** (migration 034, played on endstep): the league form's "Senza classifica" (`no_points`) and "Online" (`is_online`) checkboxes, the "Tipo" column `leagueKindLabel`'s four kinds, one open per kind (opening / creating one closes the other open one of its kind); the Eventi standalone form's **Locale / Esterno / Online switch** (since 2026-11-03, before two checkboxes — `.admin-seg` in admin.css, radios as a pill bar; Locale by default, Esterno greyed out on an existing ordinary event), "Online (endstep)" under the event's name in the list. Their entries and matches like any other event's. `admin/js/bus.js` is a tiny pub/sub so panels can notify each other of changes (e.g. new commander → refresh a dropdown elsewhere). **Every admin list is drawn by `admin/js/crud-ui.js`'s `renderTable`** — not a table any more but the public site's sub-card look (`.history-panel.no-scroll` + one `.history-item.admin-card` per row, `admin.css`): cards are **not clickable** (no hover change), only the buttons inside them. The event leaderboard, a round's matches and the claim requests use it too. **Tab counts** (`admin/js/tab-counts.js`): `setTabCount(tabName, n)` fills a small red circle after a tab's label (`.admin-tab-count`, hidden at 0 — today only "Utenti": pending link requests, set by `users-admin.js`'s `renderRequests`, so it updates whenever that list reloads); a counted tab's text is wrapped in `.admin-tab-label`, and `tabLabel(tab)` (used for the page title and as the bottom tab bar's short-name fallback) reads just that, not the number. The admin is **wider than the public site** — `--admin-max-width: 1400px` (admin.css) for `.admin-shell`, `.admin-tabs-inner` and the admin header's `.site-header-inner`, vs the public 1100px — so beside the fixed 300px form column the lists have room.

- **Admin actions can't be sent twice (`admin/js/crud-ui.js` `runBusy` / `onBusySubmit`)**: every save form goes through `onBusySubmit(form, async (e) => …)` (instead of `form.addEventListener("submit", …)`) and every action button through `runBusy(button, task)` — the list's Elimina (in `renderTable`), the open/close toggles (leagues, events, standalone events, the event's own in app.js), Matches' + Turno / delete round / standings ↑↓ / bonus field, Utenti's approve / reject / block, login / logout. Not `disabled` — some code disables / re-enables controls itself (a closed event's locked forms). **A new admin action goes through these too.**
